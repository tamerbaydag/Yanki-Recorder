# 🎛️ Yankı – Macro Recorder

**Version: 1.0.0**

Lightweight Windows macro recorder to capture & replay keyboard and mouse actions.

## ✨ Features
- 🎥 Record keyboard & mouse input
- 🔁 Infinite playback (F9 to stop)
- 📁 Save / Load macros (JSON)
- 🧲 System tray integration
- ⚡ Built with Rust

## 🛠 Build
```bash
cargo build --release
```
